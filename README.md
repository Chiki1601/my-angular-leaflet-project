# my-angular-leaflet-project

# Angular 22 + Leaflet + OpenStreetMap
This project demonstrates how to integrate Leaflet and OpenStreetMap into an Angular 22 standalone application without using Google Maps API or any billing account.


## Technologies

- Angular 22
- TypeScript
- Leaflet
- OpenStreetMap
- SCSS
- Angular Standalone Components

## Features

✅ Angular 22 standalone application
✅ Leaflet integration
✅ OpenStreetMap tiles
✅ Map initialization
✅ Marker placement
✅ Popup information
✅ Responsive map layout

## Installation

### Create Angular Project

```bash
npx @angular/cli@22 new my-leaflet-map-app

npm install leaflet
npm install --save-dev @types/leaflet


## Run Application
ng serve
